# Verse Lingua

Translate novel with Google Translate

Requirements to execute the script :-

> Execute the following command for python :-
>
> ```
> sudo dnf install python3
> ```
>
> Execute the following command for python modules :-
>
> ```
> pip install rich rich-argparse websockets
> ```
>
> Browser Extension :- `Tampermonkey`

Execute the following command to install the script :-

```
curl -sSL https://raw.githubusercontent.com/abdullah-al-jaber/verse-lingua/vanilla/shell-script/install.sh | sudo sh
```

Use `-h` or `--help` to learn about available options

Execute following command to uninstall the script :-

```
curl -sSL https://raw.githubusercontent.com/abdullah-al-jaber/verse-lingua/vanilla/shell-script/uninstall.sh | sudo sh
```
